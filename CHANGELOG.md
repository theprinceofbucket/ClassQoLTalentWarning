# Changelog

## 0.1.1

### English

- Detect the client language once at load time: German for `deDE`, English for all others.
- Prepare the current source for its first public release, with author metadata,
  MIT licensing, bilingual documentation and reproducible release packaging.
- Preserve the 37 talent markers and existing tooltip behavior.
- Owner verified German and English tooltips after changing the client language
  in the game settings and restarting the game for each language.

### Deutsch

- Client-Sprache einmal beim Laden erkennen: Deutsch bei `deDE`, sonst Englisch.
- Aktuellen Quellstand für die erste öffentliche Version vorbereiten: Autor,
  MIT-Lizenz, zweisprachige Dokumentation und reproduzierbares Release-Paket.
- Die 37 Talentmarkierungen und das bisherige Tooltip-Verhalten beibehalten.
- Deutsch und Englisch vom Projektbetreiber getestet: Client-Sprache in den
  Spieleinstellungen geändert und das Spiel für jede Sprache neu gestartet.

## 0.1.0

- Initial local version: red borders and a German tooltip for the 37 selected
  talent nodes in the original WotLK 3.3.5a talent window.
- Erste lokale Version: rote Rahmen und deutscher Tooltip für die 37 ausgewählten
  Talentknoten im originalen WotLK-3.3.5a-Talentfenster.

Earlier entries describe development milestones; old code and archives are not
part of the public source package.
