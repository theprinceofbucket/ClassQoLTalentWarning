# ClassQoL Talent Warning v0.1.1

## English

Lightweight talent markers for the original WoW WotLK 3.3.5a client and servers
using `mod-class-qol` 0.2.3 with all 37 selected talent grants enabled.

- Red borders on the selected talent nodes in your own Blizzard talent window.
- German tooltip for `deDE`; English tooltip for every other locale.
- One runtime Lua file, no libraries, settings files, server messages or polling.
- MIT source code by theprinceofbucket, with English and German documentation.

**Install:** extract `ClassQoLTalentWarning.zip` into `Interface/AddOns`.
The result must be `Interface/AddOns/ClassQoLTalentWarning/ClassQoLTalentWarning.toc`.
No build or server changes are needed.

**Downloads:** `ClassQoLTalentWarning.zip` and `SHA256SUMS.txt`.

**Test status:** initial in-game use received positive owner feedback. Local
talent-data, syntax and package checks passed. The owner successfully tested
German and English in 0.1.1 by changing the client language in the game settings
and restarting the game for each language. Additional locales, full all-class/dual-spec
compatibility and installation through the published updater source remain open.
The addon assumes the matching server
configuration; it does not verify active effects or support replacement talent windows.

Created with assistance from OpenAI ChatGPT/Codex. Independent community project;
not an official OpenAI or Blizzard product.
